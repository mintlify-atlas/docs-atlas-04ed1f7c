AGRO-JUTIAPA ships a fully self-contained single-page application (SPA) located at `front/index.html`. The front-end is orchestrated by `front/js/app.js`, which wires together reactive form validation, real-time API calls, an interactive CAD canvas (`front/js/terrain.js`), dynamic Chart.js water-balance charts (`front/js/charts.js`), and an in-browser PDF viewer powered by `html2pdf.bundle.min.js`. No build step or bundler is required — the SPA runs directly from the file system when served by the included Python server.

## Starting the Web Server

The recommended way to serve the SPA is with the included multithreaded Python server.

<Steps>
  <Step title="Open a terminal in the project root">
    Navigate to the `analizador/` directory where `server.py` lives.
  </Step>
  <Step title="Start the server on port 8000">
    ```bash
    python server.py 8000
    ```
    The server prints a confirmation banner and begins listening:

    ```
    ==================================================================
      SERVIDOR AGRO-JUTIAPA ACTIVO (Multihilo)
      Accede en tu navegador a: http://localhost:8000
    ==================================================================
    ```
  </Step>
  <Step title="Open the app in your browser">
    Navigate to [http://localhost:8000](http://localhost:8000). The SPA loads immediately from `front/index.html`.
  </Step>
</Steps>

<Note>
  The server uses Python's `ThreadingMixIn` combined with `HTTPServer` to create a `ThreadedHTTPServer` class with `daemon_threads = True`. Each incoming HTTP request is handled in its own thread, so concurrent browser requests — such as a form submission arriving while a chart image is loading — never block each other.
</Note>

You can use any available port by passing it as the first argument. For example, `python server.py 9000` starts the server on port 9000.

## Parcel Configuration

The first section of the form lets you describe the physical geometry of your maize plot. AGRO-JUTIAPA supports three shape types that reflect the irregular land boundaries typical of smallholder parcels in the Corredor Seco:

| Shape type | Spanish label | Sides required |
|---|---|---|
| `rectangulo` | Rectángulo | Width + Length |
| `cuadrilatero` | Cuadrilátero Irregular | 4 unequal sides |
| `triangulo` | Triangular | 3 sides |

<Steps>
  <Step title="Select the shape type">
    Choose **Rectángulo**, **Cuadrilátero** or **Triángulo** from the shape selector. The form fields update reactively to show the correct number of side inputs.
  </Step>
  <Step title="Enter side measurements in meters">
    Type each side length in meters. For a rectangular parcel enter **Ancho** (width) and **Largo** (length). For an irregular quadrilateral enter all four sides; for a triangle enter three sides.
  </Step>
  <Step title="Inspect the CAD preview">
    The interactive canvas rendered by `front/js/terrain.js` updates in real time as you type, drawing the polygon to scale so you can visually verify the geometry before submitting.
  </Step>
</Steps>

Areas are reported in three units simultaneously: square meters (m²), manzanas (mz, where 1 mz = 7,000 m²), and hectares (ha).

## Analysis Parameters

Once the parcel geometry is set, complete the three analysis parameters:

<CardGroup cols={3}>
  <Card title="Sowing Date" icon="calendar">
    Enter the planned sowing date in **YYYY-MM-DD** format (e.g. `2026-06-01`). The model simulates a 60-day phenological window starting on this date and also evaluates the antecedent 30-day soil moisture conditions.
  </Card>
  <Card title="Geographic Coordinates" icon="map-pin">
    Latitude and longitude of your plot. Inputs are automatically restricted to the bounding box of Calderas, San José Acatempa, Jutiapa: **lat 14.240–14.290**, **lon -90.160–-90.110**. Values outside this range are rejected with a validation error.
  </Card>
  <Card title="Investment Capital" icon="coins">
    Enter your available investment capital in **Quetzales (Q)**. This figure drives the full Profit & Loss projection, break-even calculation, and the three-scenario sensitivity matrix (Optimistic +15%, Projected, Pessimistic -55%).
  </Card>
</CardGroup>

## Reading the Results

After the form is submitted the SPA calls `POST /api/analyze` and renders the response in several panels.

### Semáforo Agronómico

The most prominent result is the tri-color traffic light, which summarizes the calibrated sowing viability at a glance:

| Color | Spanish label | Threshold | Meaning |
|---|---|---|---|
| 🟢 Verde | RECOMENDADO PARA SIEMBRA | ≥ 70 % | Hydrological conditions are highly favorable. Proceed with scheduled sowing. |
| 🟡 Amarillo | SIEMBRA CONDICIONADA | 40 %–69 % | Moderate water risk. Use early or drought-tolerant varieties and conservation tillage. |
| 🔴 Rojo | NO SEMBRAR | < 40 % | High probability of critical water stress or phenological failure. Do not sow. |

Directly below the semáforo you will see:

- **Calibrated probability %** — the sigmoid-calibrated output of the XGBoost/Logistic ensemble, e.g. `71.0%`.
- **ENSO phase** — current El Niño/La Niña/Neutral classification sourced from NOAA PSL (MEI v2 and Niño 3.4 indices), e.g. `Neutral`.

### Water Balance Chart

The dynamic chart rendered by `front/js/charts.js` (Chart.js) plots four series over the 60-day simulation window starting on your chosen sowing date:

- Daily precipitation (mm)
- Accumulated precipitation (mm)
- Accumulated crop evapotranspiration ETc (mm)
- Relative soil water fraction (fraction of total available water TAW)

### Fenological Stages Table

A four-row table shows the water streak analysis for each of the maize growth stages across the full 120-day crop cycle:

| Stage | Days |
|---|---|
| Germinación y Emergencia | Days 1–15 |
| Desarrollo Vegetativo | Days 16–55 |
| Floración y Polinización *(Critical)* | Days 56–75 |
| Llenado de Grano y Maduración | Days 76–120 |

Each row reports total rainfall (mm), maximum dry streak (days), maximum wet streak (days), and a risk level (Bajo / Moderado / Crítico). Critical blocking alerts — such as a dry streak exceeding 4 days during Floración — are highlighted separately.

## Downloading the PDF Report

The interface includes an interactive PDF viewer that lets you review the official technical dictum before saving it.

<Steps>
  <Step title="Open the PDF viewer">
    After results load, scroll to the **Dictamen Oficial** section. The embedded viewer renders the report directly in the browser using `html2pdf.bundle.min.js`, allowing you to page through all three pages before downloading.
  </Step>
  <Step title="Download the PDF">
    Click the **Descargar PDF** button. The file `Informe_Viabilidad_Maiz_Jutiapa.pdf` is saved to your browser's default downloads folder.
  </Step>
</Steps>

The PDF is structured in **three pages** in Letter format:

1. **Page 1 — Dictamen Técnico:** Semáforo verdict, calibrated probability, ENSO phase, algorithmic criteria, historical ex-post validation, phenological streak report, and the full P&L financial projection with sensitivity matrix.
2. **Page 2 — Balance Hídrico:** The water balance chart exported as a high-resolution image (`output/balance_hidrico_siembra.png`).
3. **Page 3 — Plano del Terreno:** The CAD terrain layout rendered as a vector-quality image (`output/plano_terreno.png`), showing the parcel polygon with side dimensions and area annotation.

## Real-Time MAGA Price

The financial projection in both the web results and the PDF uses the **live wholesale price of white maize** scraped in real time from the official MAGA portal.

- **Source:** MAGA SIMPA — Precios Diarios de Mercados Mayoristas, Mercado La Terminal, Ciudad de Guatemala.
- **Product:** *Maíz blanco, de primera* (per quintal).
- **Date stamp:** The exact date of the last successful scrape is shown in the financial panel next to the price, e.g. `Última actualización: 09/10/2026`.

<Note>
  If the MAGA scraper is offline or the portal is temporarily unavailable, the system falls back automatically to the default price of **Q 235.00 per quintal**. The financial projection is still calculated and the PDF is generated normally; the date stamp will reflect the fallback condition.
</Note>
