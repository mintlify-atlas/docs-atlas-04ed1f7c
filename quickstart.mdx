By the end of this guide you will have AGRO-JUTIAPA running locally, the web interface open in your browser, and a complete agrometeorological viability verdict — including a calibrated semáforo color, a full soil-water balance, and a Quetzales-denominated P&L projection — generated for a real sowing date in Calderas, San José Acatempa, Jutiapa, Guatemala. The same analysis is available both through the CLI and through the REST API, and both paths are covered here.

## Prerequisites

Before you begin, make sure you have the following installed:

- **Python 3.10 or higher** — required for the analytical engine, CLI, and local server.
- **Git** — to clone the repository.
- **Node.js 18 or higher** — optional; needed only if you plan to deploy to Vercel Serverless.

## Steps

<Steps>
  <Step title="Clone the repository and create a virtual environment">
    Clone the project and isolate its dependencies in a Python virtual environment.

    <CodeGroup>
      ```powershell Windows (PowerShell)
      git clone https://github.com/GimenaMP/analizador.git
      cd analizador
      python -m venv .venv
      .venv\Scripts\Activate.ps1
      ```

      ```bash Linux / macOS
      git clone https://github.com/GimenaMP/analizador.git
      cd analizador
      python3 -m venv .venv
      source .venv/bin/activate
      ```
    </CodeGroup>
  </Step>

  <Step title="Install Python dependencies">
    Install all required packages from `requirements.txt`. This pulls in NumPy, pandas, scikit-learn, XGBoost, Matplotlib, ReportLab (fpdf2), and the other libraries the analytical core depends on.

    ```bash
    pip install -r requirements.txt
    ```

    The full dependency list is:

    ```text requirements.txt
    numpy>=1.24.0
    pandas>=2.0.0
    requests>=2.31.0
    matplotlib>=3.7.0
    scikit-learn>=1.3.0
    xgboost>=2.0.0
    tabulate>=0.9.0
    fpdf2>=2.7.0
    ```
  </Step>

  <Step title="Start the local web server">
    Launch the multithreaded Python HTTP server on port 8000. It serves the `front/` single-page application and exposes the `/api/analyze` and `/api/maga-price` REST endpoints.

    ```bash
    python server.py 8000
    ```

    You should see the following confirmation in your terminal:

    ```text
    ==================================================================
      SERVIDOR AGRO-JUTIAPA ACTIVO (Multihilo)
      Accede en tu navegador a: http://localhost:8000
    ==================================================================
    ```

    Open [http://localhost:8000](http://localhost:8000) in your browser. The web interface loads the interactive terrain plotter (HTML5 Canvas), the soil-water balance chart (Chart.js), and the integrated PDF viewer.

    <Note>
      The first time the server handles an analysis request it downloads the full ERA5 daily series from the Open-Meteo Archive API (1981 to present) and the ENSO indices from NOAA PSL. This initial fetch may take **30–60 seconds** depending on your connection. All subsequent requests for the same coordinates are served from the local `.cache/` directory in milliseconds.
    </Note>
  </Step>

  <Step title="Run a CLI analysis with real parameters">
    The CLI (`main.py`) lets you run a headless analysis and generate a PDF verdict without touching the browser. The example below uses the centroid of Calderas, a 100 m × 70 m rectangular plot, and Q 7,200 of farmer capital:

    ```bash
    python main.py \
      --date 2026-06-01 \
      --lat 14.267 \
      --lon -90.133 \
      --width 100 \
      --length 70 \
      --capital 7200 \
      --corn-type blanco
    ```

    All available CLI flags are described in the table below:

    | Flag | Type | Default | Description |
    |---|---|---|---|
    | `--date` | `YYYY-MM-DD` | `2026-06-01` | Tentative sowing date |
    | `--lat` | float | `14.267` | Plot latitude (Calderas bounding box: 14.240–14.290) |
    | `--lon` | float | `-90.133` | Plot longitude (Calderas bounding box: −90.160–−90.110) |
    | `--shape` | string | `cuadrilatero` | Terrain shape: `cuadrilatero`, `triangulo`, or `rectangulo` |
    | `--sides` | float list | `100.0 70.0 90.0 65.0` | Side lengths in meters (4 for quadrilateral, 3 for triangle) |
    | `--width` | float | `100.0` | Width in meters (rectangular plots only) |
    | `--length` | float | `70.0` | Length in meters (rectangular plots only) |
    | `--capital` | float | `6500.0` | Farmer's own investment in Guatemalan Quetzales (Q) |
    | `--corn-type` | string | `blanco` | Maize type — currently `blanco` only |
    | `--force-refresh` | flag | off | Re-download ERA5 and NOAA data, bypassing the local cache |
    | `--no-pdf` | flag | off | Skip writing the PDF verdict to `output/` |

    <Tip>
      Pass `--force-refresh` to force AGRO-JUTIAPA to re-download the latest ERA5 archive data and NOAA ENSO indices, discarding any cached files. Use this when you need the most up-to-date climate series, for example at the start of a new growing season.
    </Tip>
  </Step>

  <Step title="Read the output — understanding the semáforo verdict">
    The CLI prints a structured agroclimate and financial report to the terminal and saves a three-page Letter-format PDF to the `output/` directory (default filename: `output/Informe_Viabilidad_Maiz_Jutiapa.pdf`).

    The core of the verdict is the **semáforo agronómico tri-color**, driven by the calibrated XGBoost probability:

    | Color | Probability range | Meaning | Recommended action |
    |---|---|---|---|
    | 🟢 **Verde** | ≥ 60 % | Sowing recommended | Proceed with standard planting density (5.8 plants/m²) |
    | 🟡 **Amarillo** | 35 % – 59 % | Conditional / Alert | Use early-maturing varieties and moisture-retention cover |
    | 🔴 **Rojo** | < 35 % | Do not sow | High probability of severe water stress or crop failure |

    Beyond the semáforo, the report includes:

    - **ENSO phase** (El Niño / La Niña / Neutral) sourced from the latest NOAA MEI v2 index.
    - **Soil-water balance** — daily ETa/ETc ratio and waterlogging-day count against the FAO-56 thresholds (ETa/ETc ≥ 0.90, waterlogging ≤ 8 days in the 60-day window).
    - **Terrain and density** — plot area in m², manzanas (1 mz = 7,000 m²), and hectares; recommended seed rate in bags of 60,000 seeds.
    - **Financial P&L** — gross income, net profit/loss, ROI %, break-even in quintales, and a three-scenario sensitivity matrix (Optimistic +15 %, Projected, Pessimistic −55 %) using the live MAGA wholesale price (Q/quintal, Mercado La Terminal).
    - **Phenological dry-spell analysis** — 120-day cycle broken into four stages with *canícula* detection.

    The generated PDF charts and the balance timeline are also saved alongside the report in `output/`.
  </Step>
</Steps>

## REST API Alternative

If you prefer to integrate AGRO-JUTIAPA into another system programmatically, you can call the `/api/analyze` endpoint directly. The web server (`server.py`) and the Vercel Node.js handler (`api/analyze.js`) both accept the same JSON payload.

**Endpoint:** `POST /api/analyze`

```json
{
  "date": "2026-06-01",
  "lat": 14.267,
  "lon": -90.133,
  "shape_type": "cuadrilatero",
  "sides": [100.0, 70.0, 90.0, 65.0],
  "capital": 7200.0,
  "corn_type": "blanco"
}
```

Run the following `curl` command against your local server (replace the `...` with the full JSON body or pass it from a file):

```bash
curl -X POST http://localhost:8000/api/analyze \
  -H 'Content-Type: application/json' \
  -d '{
    "date": "2026-06-01",
    "lat": 14.267,
    "lon": -90.133,
    "shape_type": "cuadrilatero",
    "sides": [100.0, 70.0, 90.0, 65.0],
    "capital": 7200.0,
    "corn_type": "blanco"
  }'
```

A successful response returns a JSON object containing `probabilidad`, `semaforo_color`, `semaforo_estado`, `semaforo_accion`, `fase_enso`, the full `terreno` geometry block, `densidad`, `financiero`, the 60-day `timeline` series, and the filename of the generated PDF under `report_pdf_path`.

<Note>
  The request body is limited to **10 KB** by the server's DoS protection (`MAX_REQUEST_BODY_BYTES = 10 * 1024`). Standard analysis payloads are well under this limit. Oversized requests receive a `413` response.
</Note>

You can also fetch the current live MAGA wholesale price independently:

```bash
curl http://localhost:8000/api/maga-price
```

```json
{
  "producto": "Maíz blanco, de primera",
  "mercado": "La Terminal",
  "medida": "Quintal",
  "precio": 235.0,
  "fecha": "09/10/2026",

```
